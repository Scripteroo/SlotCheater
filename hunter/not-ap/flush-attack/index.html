Flush Attack

Conditional advantage — only in active mode

⚠️ AP ONLY IN FLUSH ATTACK MODE

🎰 What this game is

Flush Attack is a banking video poker variant. After a series of qualifying flushes are dealt, the machine enters Flush Attack mode, during which subsequent flushes pay enhanced amounts.

⚠️ Why it's only conditionally AP

Flush Attack mode is the entire edge. With mode active, the increased flush payout pushes the game into +EV territory.

Without active mode, the game has standard house edge — no exploitable persistent state.

The banked-flush counter is visible on most cabinets. Check the mode indicator (and the count of flushes since reset) before committing to a session.

✅ Try instead

For non-conditional banking AP: Piggy Bankin'

For coin-collection banking: Buffalo
